Court Heading

Include:

* Name of the court
    * Judicial division
    * Location of the court
* Suit number
* Names of the parties

Deponent’s Details

State:

1. Full name
2. Occupation
3. Nationality
4. Address
5. Capacity in which the affidavit is made

Format:

I, [FULL NAME], [OCCUPATION], [NATIONALITY],
of [ADDRESS], do hereby make oath and state as follows:

Facts

Present the facts in numbered paragraphs.

1. That I am the [POSITION/RELATIONSHIP] of the [PARTY] in this matter.
2. That [STATE FACT].
3. That [STATE FACT].
4. That [STATE FACT].
5. That I make this affidavit in support of [PURPOSE].

Facts should be:

* Relevant to the matter
* Set out in numbered paragraphs
* Clear and concise
* Based on facts within the deponent’s knowledge where applicable

Exhibits

Where supporting documents are attached:

* Identify each document.
* Assign an exhibit mark.
* Refer to the exhibit in the relevant paragraph.

Example:

That the document marked Exhibit A is a true copy of
[DESCRIPTION OF DOCUMENT].
